# Celo Payroll Agent

An agent that pays contractors from an [Altana](https://altana.network/) agent wallet on Celo mainnet, under a weekly spending cap granted by a person through a session key.

Built for the Celo **Agents Open for Business** hackathon (Track 4 · Altana Agent Wallets).

## Planned scope
- Person grants the agent an Altana session key with a weekly cap, contract allowlist and expiry
- Agent reads approved contractor invoices and pays them in stablecoins on Celo mainnet inside that cap
- Agent registered with ERC-8004; Self Agent ID verification; Celo attribution tag on every transaction
- Payment log and cap usage dashboard
